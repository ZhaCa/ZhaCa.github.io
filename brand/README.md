# AgentOps 品牌标识使用规范

## 构成

图形以两条等宽轨迹构成抽象字母 A，以横向回转连接表示 Agent 运行证据返回持续优化流程。图形由本项目原创绘制。字标使用系统字体，因此在不同设备上字形会有细微差异。

| 场景 | 推荐文件 |
|---|---|
| 浅色页面横版 | `agentops-lockup.svg` |
| 深色页面横版 | `agentops-lockup-white.svg` |
| 含署名组合 | `agentops-signature.svg` / `agentops-signature-white.svg` |
| 单色印刷 | `agentops-mark-mono.svg`、`agentops-lockup-mono.svg`、`agentops-signature-mono.svg` |
| 侧栏、小尺寸 | `favicon.svg`（深蓝底白色图形） |
| PNG 输出 | `agentops-mark-512.png`、`agentops-mark-128.png`、`favicon-32.png`、`favicon-16.png` |

SVG 为首选母版。PNG 为透明背景图形或已设底色的 favicon；导出自同一 SVG。浅色背景使用蓝色 `#0B56D8`，深色背景使用白色；字标深色为 `#10233F`。图形四周留至少图形宽度的 1/8 空白，不拉伸、不旋转、不改变笔画比例。16px 场景使用有底色的 favicon，避免在复杂背景上使用透明标识。

“神州数码”在组合标识中是产品归属文字，此套图形不冒充神州数码企业 Logo。对外正式品牌应用仍需由企业品牌规范复核。
